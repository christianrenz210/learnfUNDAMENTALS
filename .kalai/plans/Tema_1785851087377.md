# Plan: Fullscreen ChatGPT-style AI Assistant UI

## Goal
Redesign the `/aiassist` page so it becomes a true fullscreen AI assistant experience:
- No top navbar and no footer when on the AI assistant page.
- Two-column layout: left sidebar (ChatGPT-style conversation list / history + new chat button) and right main chat area.
- Header toolbar only inside the assistant (model/persona name, action buttons).
- Preserve existing behavior: local conversation history, run code, open in compiler, dark mode, typing effect, chips, form, etc.
- Keep the floating widget unchanged on other pages.

## Current state
- `aiassist.html` extends `base.html`, so it inherits the global navbar + footer + floating widget.
- The existing full-page assistant in `aiassist.html` is a single centered column with a header bar, history dropdown, messages, chips, and input.
- CSS for assistant is already in `static/css/style.css` (`assist-page`, `assist-page-header`, etc.).
- Logic in `static/js/eren.js` handles history, messages, code blocks, running code, etc.

## Files to modify
1. `templates/base.html`
2. `templates/aiassist.html`
3. `static/css/style.css`
4. `static/js/eren.js` (minor, mostly CSS class / selector updates)

## Detailed plan

### 1. `templates/base.html` — make navbar/footer skippable
Add Jinja2 flags so child templates can opt out of global chrome:
- Add `{% set hide_nav = True %}` / `{% if not hide_nav %}` around the `<nav>`.
- Add `{% set hide_footer = True %}` / `{% if not hide_footer %}` around the `<footer>`.
- Add `{% set body_class = '' %}` default and use `class="{{ body_class }}"` on `<body>` so `aiassist.html` can set `body_class='assist-fullscreen-body'`.
- Keep the floating assistant widget hidden on `aiassist.html` via existing `hide_assist_widget = True`.

### 2. `templates/aiassist.html` — new fullscreen layout
Set blocks/variables:
- `{% set hide_nav = True %}`

### 3. `static/css/style.css` — new fullscreen + sidebar styles
Add new section (after existing assist styles):
- `.assist-fullscreen-body`:
  - `padding-top: 0;`
  - `overflow: hidden;`
- `.assist-fullscreen-body nav, .assist-fullscreen-body footer` are hidden (belt-and-suspenders).
- `.assist-layout`:
  - fixed position `inset: 0`
  - `display: flex`
  - `z-index: 1050` above navbar
- `.assist-sidebar`:
  - width `260px`
  - `background: #f7f8fb`
  - border-right, flex column
  - transitions for mobile slide-in
- `.assist-sidebar-head` with logo + mobile close
- `.assist-new-chat` button styled like ChatGPT "New chat"
- `.assist-sidebar-list` scrollable conversation list
- `.assist-main` flex column, fills remaining width
- `.assist-topbar` toolbar between sidebar and chat
- `.assist-chat` flex column, fills height
- `.assist-messages` flex-grow 1, overflow auto
- Mobile: sidebar becomes overlay drawer (translate-x), toggled by JS.
- Dark mode variants for sidebar, topbar, list items, hover states.

### 4. `static/js/eren.js` — adapt to new DOM
- History rendering already builds `#assistHistoryList`; keep it. Add extra CSS classes for selected/hover states.
- Update event listeners:
  - `assistNewChat` already exists.
  - Replace `assistClearHistory` if needed (still same ID).
  - Remove `assistHistoryBtn` listener (button removed).
  - Add `assistSidebarOpen` / `assistSidebarClose` listeners for mobile drawer.
- Keep `isFullPage` detection working (use `assist-page-messages` class still present on messages).
- Keep `sendMessage`, code rendering, compiler/run code unchanged.
