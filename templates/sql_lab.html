This lab simulates a vulnerable database so you can practice SQL injection safely. Everything runs in your browser - no real SQL is executed.

Objectives: (1) log in as admin without knowing the password, (2) steal usernames and passwords through the search box, (3) solve the Final Challenge by typing your own payload - no copy-paste, 3 hints available, (4) understand why parameterized queries stop the attack. {% if lab_completed %} +2 leaderboard points claimed {% endif %}

1. Login Bypass

The app builds the query by pasting your input straight into the SQL: 

SELECT * FROM users WHERE username = '<your input>' AND password = '<your input>'
2. Data Theft (UNION)

The search box is also vulnerable. It builds this query: 

SELECT name, price FROM products WHERE name LIKE '%<your input>%'
3. The Fix: Parameterized Queries

VULNERABLE (string concatenation)

username = input()
query = "SELECT * FROM users WHERE username = '" + username + "'"
The payload becomes part of the SQL itself.

SAFE (parameterized / prepared statement)

username = input()
query = "SELECT * FROM users WHERE username = ?"
cursor.execute(query, (username,))
The payload stays plain text - it can never change the SQL.
